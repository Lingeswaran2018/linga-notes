# Artificial Intelligence (AI) vs Machine Learning (ML) vs Deep Learning (DL)

## The Relationship

Think of these as **nested fields**:


![Diagram](../images/AI_ML_DL.jpg)


- **AI** is the broadest field.
- **ML** is a subset of AI.
- **DL** is a subset of ML based on neural networks.

---

# 1. Artificial Intelligence (AI)

## Technical Definition

Artificial Intelligence (AI) is the branch of computer science that develops systems capable of performing tasks that normally require human intelligence, such as reasoning, problem solving, decision making, perception, language understanding, and planning. AI includes both rule-based systems and learning-based systems. 

## Simple Definition

AI is **making machines behave intelligently like humans.**

### Example

Imagine a **smart home assistant**.

- You say: "Turn on the lights."
- The assistant understands your speech.
- It decides which light to turn on.
- It performs the action.

The entire intelligent behavior is AI.

---

# 2. Machine Learning (ML)

## Technical Definition

Machine Learning is a subset of AI where algorithms learn patterns from data and improve their performance without being explicitly programmed for every possible scenario. Instead of following fixed rules, the model learns from examples.

## Simple Definition

ML is **teaching computers using data instead of manually writing every rule.**

### Example

Suppose you want to detect spam emails.

Instead of writing rules like:

```
IF email contains "Free Money"
THEN Spam
```

You provide thousands of emails:

```
Email 1 → Spam
Email 2 → Not Spam
Email 3 → Spam
...
```

The ML model automatically learns the patterns and predicts whether new emails are spam.

---

# 3. Deep Learning (DL)

## Technical Definition

Deep Learning is a specialized subset of Machine Learning that uses **multi-layer Artificial Neural Networks (ANNs)** to automatically learn hierarchical features from large amounts of data. It requires significant computational power and large datasets. 

## Simple Definition

Deep Learning is **Machine Learning that learns using many layers of artificial neurons, similar to how the human brain processes information.**

### Example

Face Recognition

Instead of manually telling the computer:

- Detect eyes
- Detect nose
- Detect mouth

A deep neural network automatically learns:

- Edges
- Shapes
- Facial features
- Entire faces

It eventually recognizes who the person is.

# Simple Analogy

Imagine teaching a child to identify a cat.

### AI

```
Goal:
"Identify a cat."
```

The child can use any method.

---

### Machine Learning

You show the child:

```
1000 Cat Pictures
1000 Dog Pictures
```

The child learns the differences from examples.

---

### Deep Learning

Instead of explaining features, the child automatically learns:

```
Edges
↓

Whiskers
↓

Eyes
↓

Face Shape
↓

Complete Cat
```

Everything is learned automatically using many layers.

# Key Differences

| Feature | AI | ML | DL |
|----------|----|----|----|
| Goal | Simulate human intelligence | Learn from data | Learn complex patterns using neural networks |
| Scope | Broadest field | Subset of AI | Subset of ML |
| Learning Required | Not always | Yes | Yes |
| Uses Neural Networks | Optional | Sometimes | Always |
| Data Requirement | Low to High | Medium | Very High |
| Feature Engineering | Manual or Automatic | Mostly Manual | Automatic |
| Compute Requirement | Low to Medium | Medium | High (GPU/TPU) |
| Best For | Intelligent systems | Prediction and classification | Images, speech, NLP, large-scale AI |

# Interview Answer (30 Seconds)

> **Artificial Intelligence (AI)** is the broad field of creating systems that perform tasks requiring human intelligence. **Machine Learning (ML)** is a subset of AI where models learn patterns from data instead of relying on explicit programming. **Deep Learning (DL)** is a subset of ML that uses multi-layer neural networks to automatically learn complex representations from large datasets. In short, **AI is the goal, ML is one approach to achieve it, and DL is an advanced ML technique for solving complex problems like computer vision, speech recognition, and natural language processing.**
