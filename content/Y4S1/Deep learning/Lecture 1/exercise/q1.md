# 1.Compare the Following Module Learning Outcomes with Bloom's Taxonomy

## Introduction

Bloom's Revised Taxonomy is a hierarchical framework used to classify learning objectives according to cognitive complexity. The revised taxonomy consists of six levels:

1. Remember
2. Understand
3. Apply
4. Analyze
5. Evaluate
6. Create

Each level is represented by measurable action verbs that indicate the expected cognitive skills students should demonstrate. Learning outcomes are commonly written using these action verbs to ensure that assessments align with the intended level of learning. :contentReference[oaicite:0]{index=0}

# Analysis

This module emphasizes three progressively higher cognitive levels of Bloom's Revised Taxonomy:

### 1. Understand (Level 2)

Students are expected to develop a solid conceptual understanding of deep learning by explaining its principles, architectures, and underlying concepts.

### 2. Apply (Level 3)

Students move beyond theory by implementing deep learning algorithms using modern programming languages, frameworks, and tools to solve real-world predictive problems.

### 3. Evaluate (Level 5)

At the highest cognitive level addressed in this module, students critically assess and compare supervised, unsupervised, and reinforcement learning approaches, evaluating their effectiveness based on performance, accuracy, scalability, and suitability for different applications.

---

# Summary

The module follows a logical progression through Bloom's Revised Taxonomy:

- **Understand:** Build foundational knowledge of deep learning concepts.
- **Apply:** Implement deep learning models and tools to solve practical problems.
- **Evaluate:** Critically analyze and assess the effectiveness of different deep learning paradigms.

This progression ensures that students first gain conceptual knowledge, then develop practical implementation skills, and finally acquire the ability to evaluate and justify the use of different deep learning techniques in real-world scenarios.
